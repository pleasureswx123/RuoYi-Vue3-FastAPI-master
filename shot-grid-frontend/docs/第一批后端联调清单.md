# Shot Grid 第一批后端联调清单

## 1. 结论与使用边界

- 核对日期：2026-08-10。
- 核对范围：`module_shot_grid/controller`、`service`、`dao`、`entity/vo`、`entity/do`，并运行现有 Shot Grid 后端契约测试。
- **这是静态核对清单，不是联调通过报告。**本次没有启动前端、FastAPI、PostgreSQL、Redis 或真实 NAS，也没有执行完整 E2E。
- 状态含义：**已实现**＝已有自动注册 Controller、VO、Service/DAO 路径及针对性测试；**部分实现**＝底层模型或相邻能力存在，但该 HTTP 路由不完整；**仅设计**＝只在《领域模型与 API 契约》中定义；**未实现**＝设计文档也没有形成可执行的完整 HTTP 契约。
- 前端只可接入下表“已实现”路由。“部分实现”“仅设计”“未实现”一律视为**计划接口**，不得以 Mock fallback 或推测字段假装可用。

## 2. 通用真实契约

所有路由组均要求登录（`PreAuthDependency`），并逐接口检查平台权限。项目资源还要求项目成员或显式 `shotgrid:project:all` 范围；写成员和导入要求项目角色 `director`。平台超级管理员仍需对应动作权限。

Shot Grid VO 继承 `ShotGridApiModel`，snake_case 字段统一输出/接受 camelCase alias，例如 `project_id → projectId`、`selected_rows → selectedRows`、`error_key → errorKey`。普通成功响应为 `{"code":200,"msg":"操作成功","data":...}`；列表为 `{"code":200,"msg":"查询成功","rows":[...],"total":n}`。项目创建例外为真实 HTTP 202 且 body `code=202`。

领域错误处理器保留真实 HTTP 状态并返回：

```json
{"code":409,"msg":"项目代号已存在","success":false,"time":"2026-08-10T00:00:00","data":{"errorKey":"SG_PROJECT_CODE_CONFLICT","details":{}}}
```

认证/平台接口授权错误沿用平台响应，可能没有 `errorKey`。FastAPI 参数校验为 HTTP 422，其响应也不保证使用领域 `errorKey`。

项目分页查询字段为 `pageNum`（默认 1）、`pageSize`（默认 20，最大 100）、`orderByColumn`（`projectCode|projectName|deliveryDate|createTime`）、`isAsc`（`ascending|descending`）、`keyword`、`projectStatus`、`scope=all`；响应分页字段是顶层 `rows`、`total`、`code`、`msg`，不是 `data.items`。

## 3. 已实现接口总表

| HTTP 与路径 | 平台权限 | 项目要求 | 请求（camelCase） | 成功 envelope |
| --- | --- | --- | --- | --- |
| `GET /shot-grid/navigation` | `shotgrid:navigation:list` | 无项目角色 | 无 | `data: [{routeKey,title,path,icon,orderNum}]` |
| `GET /shot-grid/projects` | `shotgrid:project:list` | 默认仅本人项目；`scope=all` 另需 `shotgrid:project:all` | 第 2 节分页查询 | 顶层 `rows,total` |
| `POST /shot-grid/projects` | `shotgrid:project:add` | 创建人，无既有项目角色 | Header `X-Idempotency-Key`；项目创建 VO | **HTTP 202**，`{code:202,msg,data:{projectId,projectStatus,storageStatus,statusUrl}}` |
| `GET /shot-grid/projects/{projectId}` | `shotgrid:project:query` | 项目成员或全项目范围 | 正整数路径参数 | `data` 项目详情 |
| `GET /shot-grid/projects/{projectId}/storage` | `shotgrid:storage:path` | 项目成员或全项目范围 | 正整数路径参数 | `data:{projectId,storageStatus,projectPathSnapshot,initializedTime,lastErrorKey,lastErrorMessage,lockVersion,updateTime}` |
| `GET /shot-grid/projects/{projectId}/overview` | `shotgrid:project:overview` | 项目成员或全项目范围 | 正整数路径参数 | `data` 概览统计 |
| `GET /shot-grid/projects/{projectId}/members` | `shotgrid:member:list` | 项目成员或全项目范围 | 正整数路径参数 | 非分页顶层 `rows`，无 `total` |
| `POST /shot-grid/projects/{projectId}/members` | `shotgrid:member:add` | `director` | `{userId,projectRole,producerCode?}` | `data` 成员 |
| `PUT /shot-grid/projects/{projectId}/members/{userId}` | `shotgrid:member:edit` | `director` | `{projectRole?,producerCode?}`，至少一项 | `data` 成员 |
| `DELETE /shot-grid/projects/{projectId}/members/{userId}` | `shotgrid:member:remove` | `director` | 正整数路径参数 | `{code:200,msg:"移除成功"}` |
| `POST /shot-grid/projects/{projectId}/shots/import/preview` | `shotgrid:shot:import` | `director` | `multipart/form-data` 的 `file`（`.xlsx`） | `data:{batchId,importToken,expiresAt,summary,rows,workbookWarnings}` |
| `POST /shot-grid/projects/{projectId}/shots/import/commit` | `shotgrid:shot:import` | `director` | Header `X-Idempotency-Key`；`{importToken,selectedRows:[{sheetName,rowNumber}]}` | `data` 镜头导入结果（含 `idempotentReplay`） |
| `POST /shot-grid/projects/{projectId}/assets/import/preview` | `shotgrid:asset:import` | `director` | `multipart/form-data` 的 `file`（`.xlsx`） | `data:{batchId,importToken,expiresAt,summary,rows,workbookWarnings}` |
| `POST /shot-grid/projects/{projectId}/assets/import/commit` | `shotgrid:asset:import` | `director` | Header `X-Idempotency-Key`；`{importToken,selectedRows:[{sheetName,rowNumber}]}` | `data` 资产导入结果 |

### 3.1 请求与响应字段补充

项目创建字段：`projectCode`、`projectName`、`projectType`（仅 `ai_short_film`）、`projectDescription?`、`aspectRatio`、`plannedDurationMs?`、`deliveryDate?`、`storageRootId`、`projectDirectoryName`、`directorUserIds`（至少一人）、`members:[{userId,projectRole,producerCode?}]`、`remark?`。`projectRole` 仅 `director|creator`；`producerCode` 规范化为 2—12 位大写字母或数字。

概览字段：`currentPhase`，以及 `total/completed/pendingReview/revision/unassigned` 的 shots、assets、assetItems 统计和 `overallProgress`。项目列表项另含 `projectId/projectCode/projectName/projectType/projectTypeName/aspectRatio/plannedDurationMs/deliveryDate/projectStatus/storageStatus/myProjectRole/lockVersion`；详情增加描述、`allowedActions` 与审计字段。

镜头提交结果：`batchId,committedRows,createdEpisodes,reusedEpisodes,createdScenes,reusedScenes,createdShots,createdTasks,createdAssetLinks,createdAssetRequirements,createdStorageOperations,idempotentReplay`。资产提交结果：`batchId,committedRows,createdAssetsByType,reusedAssets,createdAssetItems,createdTasks,missingProductionItemWarnings,autoMatchedRequirements,pendingRequirements,conflictRequirements`。

**幂等重放：**镜头提交的响应显式返回 `idempotentReplay=true`。资产提交会从 `sg_import_batch.result_snapshot` 耐久重放相同结果，但当前 `AssetImportCommitResultModel` **没有** `idempotentReplay` 字段；前端不得假设两者字段相同。同一幂等键但 Token/选中行不同返回 409 `SG_IDEMPOTENCY_CONFLICT`。

### 4.3 错误样例

```json
{"code":403,"msg":"当前项目角色无权执行该操作","success":false,"time":"2026-08-10T00:00:00","data":{"errorKey":"SG_PROJECT_ACCESS_DENIED","details":{}}}
```

```json
{"code":409,"msg":"项目存储尚未就绪，不能导入镜头","success":false,"time":"2026-08-10T00:00:00","data":{"errorKey":"SG_PROJECT_NOT_READY","details":{}}}
```

常见领域状态/键：400 `SG_IMPORT_TOKEN_INVALID`；401 `SG_CURRENT_USER_INVALID`；403 `SG_PROJECT_ACCESS_DENIED`、`SG_IMPORT_TOKEN_FORBIDDEN`；404 `SG_PROJECT_NOT_FOUND`、`SG_MEMBER_NOT_FOUND`、`SG_IMPORT_BATCH_NOT_FOUND`；409 `SG_PROJECT_CODE_CONFLICT`、`SG_STORAGE_PATH_CONFLICT`、`SG_MEMBER_ALREADY_EXISTS`、`SG_LAST_DIRECTOR_REQUIRED`、`SG_IMPORT_BATCH_STATE_CONFLICT`、`SG_IDEMPOTENCY_CONFLICT`、`SG_ASSET_NAME_CONFLICT`；410 `SG_IMPORT_TOKEN_EXPIRED`；413 `SG_IMPORT_WORKBOOK_TOO_COMPLEX`、`SG_IMPORT_PREVIEW_TOO_LARGE`；422 `SG_PROJECT_ID_INVALID`、`SG_IMPORT_FILE_INVALID`、`SG_IMPORT_HAS_ERRORS`；500 `SG_IMPORT_COMMIT_FAILED`；503 `SG_IMPORT_PREVIEW_STORE_UNAVAILABLE`、`SG_STORAGE_ROOT_UNAVAILABLE`。

## 5. 计划接口清单

### 5.1 部分实现（底层存在，HTTP 契约缺口仍阻止前端接入）

- 项目存储已能查询，但存储根目录 options/path-preview/admin/probe、项目存储 retry 和 storage-operation retry 没有 Controller。
- 导入已能预检/提交，但镜头/资产模板下载、导入批次列表与结果查询没有 Controller。
- DO 已覆盖 episode、scene、shot、asset、asset item、task、version、note、review list、storage operation 等实体，但不能据此推断其 CRUD HTTP API 已实现。

### 5.2 仅设计（均为计划接口）

- 项目：`PUT /projects/{projectId}`、`POST .../archive|start|complete`。
- 集/场次/镜头：集创建/归档，场次列表/创建/归档，镜头列表/创建/详情/修改/归档。
- 资产与需求：资产创建/归档、制作分项创建/归档，需求 resolve/ignore/rematch。
- 任务与版本：镜头/资产分配，任务列表/详情/修改/开始，版本提交与重试、版本审核动作。
- 意见/审核单/文件：意见创建/回复/解决，审核单创建、增删版本、激活/完成/归档，版本文件下载与镜头/资产 NAS 路径。
- 文档第 10 节中的 storage roots、template、imports 查询以及上述所有路由，除第 3 节明确列出的 14 个路由外，全部按计划接口处理。

### 5.3 未实现

独立 `shot-grid-frontend` 的真实 API 接入、完整前后端联调、真实 PostgreSQL/Redis/NAS 验证及完整 E2E 均未在本清单中实现或验证。
