# Shot Grid 系统使用说明

> 面向公司内部项目管理人、制作人员、审核人员及协作部门
> 文档版本：V1.0
> 更新日期：2026-08-24

## 1. 文档目的

Shot Grid 是公司内部的影视制作协作平台，用于统一管理项目、镜头、资产、制作任务、版本、审核问题和正式文件。

阅读本说明后，你可以根据自己的角色完成以下工作：

- 项目管理人：创建项目、添加成员、导入镜头和资产、分配任务、审核版本、查看 NAS 状态。
- 制作人员：查看本人任务、等待管理人员确认开工、提交作品、根据审核问题修改并提交新版本。
- 审核人员：检查作品、记录问题草稿、对历史问题逐条确认、通过或退回版本。

本文按当前系统实际页面和按钮编写。不同账号看到的菜单和按钮可能不同，这是正常的权限控制结果。

## 2. 使用前先了解

### 2.1 系统负责什么

系统负责把以下业务连接成一条可追溯的制作链：

~~~text
项目
  → 镜头或资产制作分项
  → 分配制作任务
  → 制作人员在线下完成作品
  → 上传并形成不可覆盖的新版本
  → 项目管理人审核
  → 通过完成，或退回修改后继续提交下一版本
~~~

系统不提供在线视频剪辑、在线图片编辑、AI 自动生成、匿名分享或外部客户门户。视频和图片仍在本地专业软件中制作，Shot Grid 负责收任务、收版本、留历史和闭环审核。

### 2.2 访问方式

- 访问地址：以公司内部通知或系统管理员提供的地址为准。
- 登录账号：由平台管理员统一创建和分配，不需要单独注册 Shot Grid 账号。
- 推荐环境：使用公司允许的新版 Chrome 或 Edge 浏览器，保持网络和公司 NAS 访问环境正常。
- 首次使用：如登录后没有菜单或项目，请先联系项目管理人确认你已加入项目，并确认平台权限已开通。

### 2.3 三条重要规则

1. 项目管理人分配镜头或资产制作分项后，还须线下确认开工条件并点击“开始任务”；资产多个制作分项分别确认，所有版本仍由当前制作人员提交。
2. 已提交版本不会被覆盖。修改后必须提交 V002、V003 等新版本，旧版本始终保留。
3. 审核人保存的“问题草稿”暂时只对审核方可见；点击“退回并发送问题”后，制作人员才会看到正式修改问题。

## 3. 角色和职责

| 角色 | 主要工作 | 不能做的事 |
| --- | --- | --- |
| 平台管理员 | 创建账号、维护平台权限、配置可用 NAS 根目录、处理平台级异常 | 确认镜头或资产分项开工还需相应接口权限与项目管理范围；不能代替制作人员提交版本 |
| 项目管理人 | 创建和维护项目、管理成员、镜头和资产、分配任务、确认镜头或资产分项开工、审核版本、确认最终版 | 不能代替当前受派制作人员提交作品 |
| 制作人员 | 查看本人任务、等待管理人员确认开工、上传作品、处理退回问题、提交新版本 | 不能管理成员、给自己分配其他任务或执行最终审核 |

同一个人在不同项目中的角色可以不同。项目内角色和平台权限缺一不可；页面不显示某个按钮时，通常表示当前账号、项目状态或资源状态不允许该操作。

## 4. 登录和界面导航

### 4.1 登录系统

1. 打开公司提供的 Shot Grid 地址。
2. 输入平台分配的“账号”和“密码”。
3. 如页面显示验证码，输入验证码；看不清时点击验证码图片刷新。
4. 点击“进入工作区”，也可以在密码或验证码输入框按 Enter。
5. 登录成功后默认进入“工作台”。

请勿把账号、密码或登录后的页面信息转发给无权限人员。退出时点击页面右上角“退出”，并在确认框中再次点击“退出”。

### 4.2 六个一级菜单

| 菜单 | 用途 |
| --- | --- |
| 工作台 | 查看本人制作任务、待我审核和最近提交 |
| 项目 | 查看或创建项目，维护成员、阶段和项目 NAS 状态 |
| 镜头管理 | 新建、导入、筛选、排序、分配和查看镜头 |
| 资产库管理 | 管理角色、场景、道具及其制作分项 |
| 版本审核 | 查看自动审核单和人工批量审核单，完成审核闭环 |
| 文件与 NAS | 查找、预览、下载正式版本文件，查看项目存储路径和目录状态 |

### 4.3 常用顶部功能

- 全局搜索：点击顶部“搜索”，或按 Ctrl + K，输入至少 2 个字符，可搜索有权访问的镜头、资产和文件。
- 全屏：点击全屏按钮进入或退出全屏；无法退出时可按 Esc。
- 主题：可切换浅色、深色或跟随系统的显示模式。
- 账号信息：右上角显示当前登录账号，操作前请确认不是借用他人账号。

## 5. 项目管理人操作指南

### 5.1 创建项目

入口：项目 → 创建项目

1. 填写“项目名称”。项目名称同时用于 NAS 项目目录名称，请使用正式、稳定的名称。
2. 填写“项目代号”。项目代号为 2—12 位大写英文字母或数字，例如 LCFR，会进入正式业务文件名。
3. 选择画幅：16:9、21:9、2.39:1、9:16 或 1:1。
4. 项目类型当前固定为“AI 影视短片”。
5. 选择可用的“NAS 根目录”。如果没有可选项，请联系平台管理员配置或检查 NAS。
6. 查看“项目保存路径”预览，确认根目录和完整路径正确且没有冲突。
7. 在“项目成员”中添加人员，并设置为“项目管理人”或“制作人员”。当前账号默认加入；项目至少要保留一名项目管理人。
8. 按需填写项目描述和备注。
9. 点击“创建并初始化 NAS”。不要连续重复点击。
10. 创建后打开项目，确认“存储状态”为“存储就绪”再开展正式业务。

如果项目显示“目录初始化中”，请等待并刷新；如果显示“存储异常”，进入项目详情的“项目存储与目录状态”查看错误并联系管理员处理，不要另建一个重名项目。

### 5.2 维护项目和成员

入口：项目 → 点击项目卡片

项目详情可查看项目状态、当前阶段、整体进度、成员和存储信息。

- 点击“编辑项目”：可修改项目名称、当前阶段、画幅、项目描述和备注。
- 项目代号和 NAS 路径创建后不能在普通编辑中修改。
- 在“项目成员”中按账号或姓名搜索平台用户，选择项目角色后点击“添加”。
- 点击成员行的“编辑”可调整项目角色；点击“移除”前，应先处理该成员尚未完成的任务。
- 项目必须始终保留至少一名活动项目管理人。
- 成员或角色调整后，目标用户如果已打开系统，需要刷新页面或重新登录才能获得新的菜单和按钮。

### 5.3 查看项目 NAS 状态

项目详情下方的“项目存储与目录状态”用于：

- 查看并复制项目 NAS 完整路径；
- 查看项目初始化、集目录、镜头目录、资产目录和目录核验记录；
- 查看等待执行、执行中、成功、失败和等待重试等状态；
- 在有权限且操作允许时填写原因并“提交重试”。

目录重试会新增一条记录，原失败记录保留用于审计。不要直接在 NAS 中随意重命名系统管理的目录或正式版本文件。

### 5.4 建立镜头数据

入口：镜头管理 → 选择当前项目

有两种方式：少量数据可手工新建，大批量数据建议使用官方 Excel 模板导入。

#### 方式 A：手工新建

1. 先点击“新建集”，填写集号、名称等信息。
2. 点击“新建场次”，选择所属集并填写场次号和名称。000 表示“序”。
3. 点击“新建镜头”，选择集、场次和场内位置。
4. 填写制作内容描述，以及景别、机位、镜头运动、焦段、台词、音效、色调参考和备注等信息。
5. 点击“创建镜头”。新镜头状态为“待分配”，此时不会自动创建任务。

系统会按场内顺序自动生成 0001、0002 等镜序代码，不需要手工维护。

#### 方式 B：Excel 导入

1. 点击“导入 Excel”。
2. 点击“下载官方模板”，始终使用系统当前下载的模板，不要使用历史样表。
3. 镜头模板中每个可见 Sheet 表示一集，Sheet 名使用 EP001、EP002 等格式。
4. 不要修改模板表头、工作表命名规则或数据结构；导入模板中不填写制作人。
5. 点击“选择文件”，选择 .xlsx 文件。当前页面提示单文件最大 10 MiB。
6. 点击“预览导入内容”。
7. 检查汇总中的有效行、警告行、错误行，以及集/场次/镜头数量。
8. 错误行不能选择，应先修改 Excel 后重新预览；警告行需要确认业务内容是否可接受。
9. 勾选需要导入的行，点击“确认导入 N 条”。
10. 看到“镜头导入完成”后再关闭弹窗。

导入只创建镜头，不创建制作任务。Excel 中的场景名称若能唯一匹配现有场景资产，系统会自动关联；不能唯一匹配的内容会保留为待处理需求，不会偷偷创建正式资产。

#### 镜头查询、排序和删除

- 可按集、场次、状态、制作人和关键字组合筛选。
- 可切换“表格、卡片、故事板”三种视图，三种视图展示同一批数据。
- 只有在表格视图中选定具体集和场次、清空其他附加筛选并完整加载该场次后，才可能使用拖拽调整顺序。
- 已开始制作、已有版本或已冻结目录的镜头不能普通改序或删除。
- 删除后系统会自动连续化剩余镜头；如系统拒绝删除，应以页面错误为准，不要直接删除 NAS 目录。

### 5.5 建立资产数据

入口：资产库管理 → 选择当前项目

资产类型当前只有三类：

- 角色（Character）
- 场景（Environment）
- 道具（Prop）

一个资产可以包含多个“制作分项”。例如一个角色资产可以包含正面设定、侧面设定和表情设计；每个制作分项都会独立分配、提交版本和审核。

#### 方式 A：手工新建资产

1. 点击“新建资产”。
2. 选择资产类型，填写资产名称、排序、资产描述和备注。资产描述由下面所有制作分项共用。
3. 添加一个或多个“首批制作分项”。分项名称允许稍后补齐，但未补齐前不能分配任务或提交版本。
4. 点击保存。新资产和分项保持“待分配”。

#### 方式 B：Excel 导入资产

1. 点击“导入 Excel”，再点击“下载官方模板”。
2. 按模板填写类型、名称、描述、制作分项、备注和状态，不要自行新增资产类型，也不要添加制作人列。
3. 选择 .xlsx 文件并点击“预览导入内容”。
4. 检查每行的类型、资产、制作分项和数据状态。
5. 修正错误行；缺少制作分项的警告行可以先导入，但后续必须进入资产详情补齐。
6. 勾选需要导入的行，点击“确认导入 N 条”。
7. 完成页会显示新增分项、自动匹配、待处理和冲突数量。

Excel 中的“描述”属于整个资产；例如同一舱室的主视角和反打视角共用这份描述。若需要各视角独有的要求，可以增加“分项补充要求”列逐行填写，也可以导入后再补充。没有这列时留空，不用重复填写资产描述。Excel 的“备注”属于对应行的制作分项。

#### 编辑资产与编辑制作分项

- “编辑资产”修改资产描述、排序和资产内部备注；资产类型和名称只读。任一分项开工后，资产描述也只读，排序和内部备注仍可修改。
- “编辑分项”修改该分项的名称、补充要求、排序和备注；上方显示的资产描述只供核对，不能在这里改动。该分项开工后禁止普通编辑。
- 列表中，资产描述只在父资产行显示，分项行只显示自身补充要求；没有补充要求时显示“—”，不代表制作信息缺失。分项详情、分配任务、开始任务和制作人任务页面仍保留完整制作信息。

资产页支持按项目、类型、状态、制作人和关键字筛选，并可切换“表格、卡片、类型看板”。父资产的状态是其全部活动制作分项状态的汇总。

### 5.6 分配或改派任务

#### 分配镜头任务

- 单个分配：打开镜头“详情”，点击“分配任务”。
- 批量分配：在镜头表格中勾选可操作镜头，点击“批量分配”。
- 选择当前项目中的“制作人员”，设置优先级和截止日期后确认。
- 首次分配会创建唯一镜头视频任务；以后“改派任务”只更换负责人，不会新建第二个任务。

#### 分配资产任务

- 单个分配：打开资产详情，在具体制作分项右侧点击“分配任务”。
- 批量分配：在资产表格中勾选资产，可把这些资产的全部活动制作分项分配给同一位制作人员。
- 填写任务要求、优先级和截止日期后确认。

分配前请认真核对制作内容、制作分项、任务要求、负责人和截止日期。镜头或资产制作分项由管理人员确认开工后，制作资料会冻结，普通编辑和改派可能被系统拒绝。

### 5.7 审核版本

入口：工作台 → 待我审核，或 版本审核 → 选择项目 → 打开待审核单

每次制作人员成功提交版本，系统都会自动创建一张“自动单版”审核单。

审核页面按三步完成：

1. **播放并检查作品**
   - 先阅读“审核依据”和任务补充要求。
   - 播放视频或查看图片；需要时使用“与上一版对比”。
   - 发现问题时点击“记录这个画面的问题”或“标注此画面”。
2. **记录发现的问题**
   - 可使用点、框选、箭头或文字标注，也可以只填写文字意见。
   - 填写“问题描述”和“修改目标”，点击“保存问题草稿”。
   - 已保存草稿可以编辑或删除；草稿阶段制作人员不可见。
3. **提交审核结论**
   - 全部符合：点击“全部符合，确认通过”。当前版本成为最终版本，任务完成。
   - 需要修改：至少保存一条新问题草稿，或把历史问题确认成“仍然存在”，再点击“退回并发送问题”。草稿此时才正式发布给制作人员。
   - 暂时不决定：点击“稍后决定”。版本继续保持待审核，问题草稿仍只对审核方可见。

审核 V002 及后续版本时，必须先对每条“上轮问题”选择：

- “已修复”：确认该问题在当前版本已经解决。
- “仍然存在”：必须填写具体原因，便于制作人员下一轮准确修改。

只有所有历史问题都已确认修复、当前版本没有新问题草稿时，系统才允许通过。审核动作提交后不可覆盖，请在点击前再次核对当前版本号和结论。

### 5.8 创建人工批量审核单

入口：版本审核 → 选择项目 → 创建批量审核单

1. 填写审核单名称、审核日期和可选说明。
2. 选择同一项目中的多个待审核版本。
3. 点击“创建审核单”。新审核单先保持“草稿”。
4. 打开批量审核单，确认版本队列后点击“激活审核单”。
5. 按队列逐个选择版本，并使用与自动审核单相同的审核流程。
6. 全部处理后点击“完成审核单”；不再使用时可按权限“归档”。

人工批量审核单只是把多个版本组织在一起，不会改变它们原有的自动审核单、任务和版本历史。

### 5.9 完成或归档项目

- “当前阶段”用于业务展示，可在“编辑项目”中从制作规划逐步更新到项目完成。
- 阶段名称不会代替真实任务状态；仍需完成镜头、资产、版本和审核闭环。
- 点击“归档”前必须填写归档原因。
- 归档不是删除：项目记录、版本、问题、文件和 NAS 内容都会保留，但项目转为只读。
- 当前系统不提供普通业务恢复入口，也不提供永久删除整个项目 NAS 目录的能力。

## 6. 制作人员操作指南

### 6.1 找到自己的任务

入口：工作台 → 我的制作任务

工作台只展示分配给当前账号的任务。可按以下条件筛选：

- 关键字：任务、项目、镜头或资产；
- 任务类型：镜头视频或资产图片；
- 状态：待开工、目录准备中、制作中、待审核、待修订、已完成；
- 优先级和截止日期；
- 最近更新、截止日期、优先级或创建时间排序。

点击任务行进入任务详情。开始前先核对项目、生产对象、完整制作要求、补充要求、优先级和截止日期；如内容有误，请先联系项目管理人修改。

### 6.2 等待管理人员确认开工

**镜头任务：管理人员确认开工。**

1. 分配后，制作人员会在工作台看到“待开工”的本人任务，可以查看要求，但不能开始或提交版本。
2. 项目管理人在线下检查本镜头需要的角色、场景、道具等资产是否齐备。
3. 确认具备条件后，进入“镜头管理”，找到对应镜头，点击该行“开始任务”。
4. 在确认框核对镜头和制作人员，点击“确认开工”。如暂不具备条件，点击“暂不开工”，任务仍待开工。
5. 系统准备 NAS 镜头目录；任务详情会自动更新，进入“制作中”后制作人员可以制作并提交，不需要再次点击开始。

**资产任务：管理人员按制作分项分别确认。**

1. 在“资产库管理”分配制作人员后，对应分项显示“待开工”；没有分配的分项仍是“待分配”。
2. 管理人员在线下确认该分项的要求和所需资料齐备，在资产列表点击“选择分项开工”，打开详情后选择待开工的制作分项。
3. 点击该分项“开始任务”，核对资产、分项和当前制作人员，再确认开工。取消不会改变状态。
4. 只有这个分项开始；同一资产的其他分项仍保持原状态。目录未就绪时等待“目录准备中”，已就绪则直接进入“制作中”。
5. 列表显示各状态的分项数量，并自动更新待开工/目录准备中的状态。制作人员在工作台或任务详情等待更新，不能自行开工，进入制作中后才可提交版本。

例如：一个角色有“正面图”“侧面图”“背面图”三个分项。正面图确认开工后，侧面图可以继续待开工，未分配的背面图仍待分配；共享目录就绪不会自动开始另外两个分项。

若目录长时间未就绪或显示异常，不要重复开工，联系项目管理人检查目录记录。自动刷新遇到权限失效会停止；网络连续失败时可点击“刷新”重新查询。系统只能限制平台内的提交操作，不能阻止制作人员在外部软件提前制作。

平台管理员上线检查：通过平台角色权限配置，显式为 `shotgrid_admin` 勾选 `shotgrid:task:start`（“开始任务”），保存并刷新权限缓存/会话。只有同时具备平台权限和当前项目管理范围的账号才能确认镜头或资产制作分项开工；制作人员即使保留旧权限也不能自行开工。

开始后请在线下软件中完成制作，不要手工改动系统生成的目录结构和业务文件名。此阶段资产齐备由管理人员线下确认，系统不自动检查依赖；确认记录可追溯到管理人及确认时间。

### 6.3 提交首个版本

入口：任务详情 → 版本提交与历史 → 提交新版本

1. 确认任务处于“制作中”。
2. 点击“选择离线制作成果”。
3. 镜头视频任务只选择 MP4 或 MOV；资产图片任务只选择 JPG 或 PNG。
4. 当前页面提示文件最大 100 MiB；部署环境如有更严格限制，以页面报错为准。
5. 填写“本轮修改说明”，说明本版本完成内容和需要审核人关注的部分。
6. 点击“上传并提交版本”。
7. 保持页面打开，查看上传、文件保存、版本生成和审核准备进度。
8. 只有页面显示提交完成并生成 V001，才表示正式版本创建成功。

提交成功后，任务进入“待审核”，系统自动创建审核单。请勿通过刷新、双击或重复上传来“催促”系统。

### 6.4 处理退回问题并提交修订版本

当任务状态变为“待修订”时：

1. 打开任务详情，在版本历史和“本版待处理问题与审核记录”中查看所有未关闭问题。
2. 点击问题可查看来源版本、文字、时间点和画面标注。
3. 根据问题在本地修改作品。
4. 重新进入“提交新版本”，为每条问题选择“已处理”或“未处理”。
5. 选择“未处理”时必须填写原因和后续计划。
6. 填写本轮总体修改说明，选择新文件，点击“上传并提交版本”。
7. 系统会创建 V002、V003 等新版本，不会覆盖旧版本。

选择“已处理”只是制作人员的本轮说明，不会自动关闭问题；问题是否真正解决，仍由审核人员在新版本上逐条确认。

### 6.5 提交异常时怎么做

- 显示“仍在等待处理”：先等待，再点击“刷新状态”，不要另开一个新提交。
- 页面刷新后看不到进度：重新打开任务，系统会尝试恢复当前未完成提交。
- 显示“版本发布失败”：点击“重试当前提交”。失败提交未处理前不能选择新文件创建第二条提交。
- 显示文件已上传但正式版本尚未生成：优先重试创建版本，不要重复上传同一个文件。
- 403 或按钮消失：可能已被改派、移出项目或权限变化，联系项目管理人并刷新或重新登录。

## 7. 文件与 NAS 的使用

入口：文件与 NAS → 选择当前项目

此页面只显示已经成功形成正式版本的业务文件。

1. 选择项目。
2. 可按业务文件名、原文件名或任务名搜索。
3. 可按文件用途、制作对象和版本状态筛选。
4. 在文件卡片中查看业务文件名、所属任务、版本号、文件大小和提交时间。
5. 点击“复制路径”复制 NAS 相对路径；点击“下载”通过受保护接口下载文件。
6. 页面下方可查看项目 NAS 完整路径和目录操作状态。

正式文件必须通过系统授权访问。不要把 NAS 路径、下载文件或审核内容提供给项目外人员；也不要在 NAS 中直接覆盖、删除或改名正式版本文件。

## 8. 常见状态说明

### 8.1 任务、镜头和资产状态

| 页面显示 | 含义 | 下一步 |
| --- | --- | --- |
| 待分配 | 生产对象已建立，但还没有制作任务 | 项目管理人分配制作人员 |
| 待开工 | 镜头或资产分项已分配，等待管理人员放行 | 管理人员线下确认条件，在镜头管理或资产制作分项点击“开始任务” |
| 目录准备中 | 镜头或资产任务正在准备 NAS 目录 | 等待系统处理；异常时由管理人查看目录记录 |
| 制作中 | 可以在线下制作并提交版本 | 制作人员提交作品 |
| 待审核 | 已提交版本，等待审核结论 | 审核人员检查并处理 |
| 待修订 / 修改中 | 版本被退回，存在待处理问题 | 制作人员修改并提交新版本 |
| 已完成 | 最终版本已通过 | 查看和交付最终版本，不再普通覆盖 |

### 8.2 版本状态

| 页面显示 | 含义 |
| --- | --- |
| 待审核 | 当前版本等待审核 |
| 已退回 | 当前版本未通过，历史仍保留 |
| 最终版本 | 审核通过并被确认为当前任务最终交付版本 |

### 8.3 项目和存储状态

| 页面显示 | 含义 |
| --- | --- |
| 准备中 | 项目正在准备成员、数据或目录 |
| 进行中 | 项目处于正常制作和审核阶段 |
| 已完成 | 项目纳入交付的工作已完成 |
| 已归档 | 项目只读保留，不再开展日常写操作 |
| 目录初始化中 | 项目 NAS 初始目录正在建立 |
| 存储就绪 | 项目可以开展正式业务 |
| 存储异常 | NAS 初始化或访问出现问题，需要查看记录和处理 |

## 9. 推荐的完整业务顺序

下面是一条适合首次使用的标准流程：

1. 平台管理员准备账号、角色权限和可用 NAS 根目录。
2. 项目管理人创建项目并添加项目管理人、制作人员。
3. 确认项目“存储就绪”。
4. 项目管理人下载官方镜头模板，填写后预览并导入镜头。
5. 项目管理人下载官方资产模板，导入角色、场景、道具及制作分项。
6. 检查镜头和资产信息，补齐缺失制作分项。
7. 项目管理人给镜头或资产制作分项分配制作人员、优先级和截止日期。
8. 项目管理人线下确认开工条件后，在镜头管理确认对应镜头，或在资产库详情逐个确认制作分项。等待目录就绪进入“制作中”，制作人员无需再次点击开始。
9. 制作人员在线下完成作品，在任务详情上传并提交 V001。
10. 项目管理人在“待我审核”或“版本审核”中打开 V001 审核单。
11. 如需修改，审核人员保存问题草稿并点击“退回并发送问题”。
12. 制作人员查看问题、线下修改、逐条说明处理情况并提交 V002。
13. 审核人员逐条确认历史问题；全部解决后点击“全部符合，确认通过”。
14. 在“文件与 NAS”中查找并下载最终版本。
15. 项目全部完成后更新项目阶段；不再开展业务时填写原因并归档。

## 10. 常见问题

### 10.1 登录后没有菜单或项目

先刷新页面或重新登录。如果仍没有，请联系项目管理人确认你已加入项目，并请平台管理员确认相应 Shot Grid 权限已启用。

### 10.2 页面没有“创建、编辑、分配、开始、提交或审核”按钮

按钮由平台权限、项目成员身份、项目角色、负责人、项目状态和资源状态共同决定。先确认当前账号和项目；仍有疑问时把页面名称、项目代号、对象名称和错误提示发给项目管理人，不要只截一个空白按钮区域。

### 10.3 提示“数据状态已发生变化”或 HTTP 409

说明其他人刚刚更新了数据，或当前页面信息已经过期。点击“刷新”，重新核对最新状态后再操作，不要反复提交旧表单。

### 10.4 Excel 预览有错误行

错误行不能导入。根据“数据状态”提示修改原 Excel，重新选择文件并预览。不要直接修改页面预览来绕过模板规则。

### 10.5 导入后为什么没有制作任务

这是正常设计。导入只建立镜头、资产和制作分项；项目管理人必须随后使用“分配任务”或批量分配，系统才会创建唯一任务。

### 10.6 镜头开始后为什么不能编辑或拖拽排序

开始制作后，镜头号会进入 NAS 目录和业务文件名语义，系统会冻结影响历史的普通修改。确需调整时，请联系项目管理人和管理员评估受控处理方案，不要直接改 NAS。

### 10.7 审核人保存了问题，制作人员为什么看不到

“保存问题草稿”只保存审核方私有草稿。审核人还需要点击“退回并发送问题”，草稿才会发布为正式修改问题。

### 10.8 为什么有问题时不能点“确认通过”

所有历史问题必须逐条确认“已修复”，当前版本也不能存在新问题或待发布问题草稿。否则系统会阻止通过，避免遗漏修改要求。

### 10.9 文件中心找不到刚上传的文件

文件中心只展示已经成功形成正式版本的文件。回到任务详情查看提交状态；只有提交完成并生成版本后，文件才会出现。

### 10.10 NAS 或目录操作失败

保留页面错误提示和操作 ID，联系项目管理人或平台管理员。不要手工创建同名项目、删除目录或重复上传来规避错误。

## 11. 提交问题时请提供的信息

向项目管理人或平台管理员反馈问题时，请尽量一次提供：

- 当前登录账号；
- 项目名称和项目代号；
- 所在页面，例如“镜头管理”“任务详情”或“版本审核”；
- 镜头号、资产名称、任务 ID、版本号或审核单名称；
- 操作步骤和页面完整错误提示；
- 问题发生时间；
- 是否刷新、重新登录或更换网络后仍可复现。

请勿在问题截图或聊天中发送密码、登录 Token、真实密钥、NAS 凭据或无关敏感数据。

## 12. 使用检查清单

### 项目管理人

- [ ] 项目代号、画幅、NAS 路径和成员已确认。
- [ ] 项目存储状态为“存储就绪”。
- [ ] 镜头和资产使用当前官方模板导入，错误行已修正。
- [ ] 制作分项名称、制作要求、负责人、优先级和截止日期已核对。
- [ ] 审核前确认当前版本号和制作依据。
- [ ] 退回时已保存并发送明确问题；通过前所有问题已关闭。

### 制作人员

- [ ] 只操作当前分配给本人的任务。
- [ ] 开始前已核对完整制作要求和截止日期。
- [ ] 文件格式和大小符合页面要求。
- [ ] 本轮修改说明已填写。
- [ ] 修订版本中每条问题都已选择处理状态，未处理原因已填写。
- [ ] 页面已经显示正式版本提交成功，没有重复上传或覆盖 NAS 文件。

### 审核人员

- [ ] 已阅读审核依据并核对当前版本号。
- [ ] 历史问题已逐条确认；“仍然存在”已写明原因。
- [ ] 新问题包含清晰的问题描述、修改目标或有效画面标注。
- [ ] 已确认是保存草稿、稍后决定、退回发送还是最终通过。
- [ ] 没有把私有草稿误认为已发送给制作人员。
