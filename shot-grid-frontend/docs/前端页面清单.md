# Shot Grid 前端页面清单

## 1. 维护规则

本清单以 `src/router/routes.js` 的静态路由为事实来源，用于明确正式路由与 Vue 页面文件的唯一维护入口。路由可以复用同一个通用页面（例如全局列表与项目范围列表），但同一路由不得同时存在另一份语义不同的占位实现。

调整正式路由时必须同步更新本清单；页面文件不在清单中且未被组件异步导入时，应删除或明确记录其非路由用途。

## 5. 占位与空态审计

对 `src/`、`tests/` 和 `docs/` 中的 `EmptyState`、`FeatureUnavailable`、`Mock`、`mock` 及“API 接入后”进行了逐项检查：

- `EmptyState` 是共享空数据组件；项目、工作台和文件页均先调用真实 API，并分别处理加载、失败或无权限状态，空结果才显示该组件，属于正常空态。
- `FeatureUnavailable` 由路由守卫在服务端导航只包含客户端未知路由键时跳转，属于白名单不匹配的安全失败页，不代表对应业务尚未实现。
- 正式 `src/` 中唯一的“API 接入后”提示位于已删除的 `ProjectListView.vue`；删除后生产源码不存在 Mock 回退或待接 API 提示。
- 文档中的 `Mock`/`mock` 均用于描述历史参考项目、验收口径或“生产环境禁止失败回退 Mock”的约束，不是正式页面的数据源或未完成提示。
