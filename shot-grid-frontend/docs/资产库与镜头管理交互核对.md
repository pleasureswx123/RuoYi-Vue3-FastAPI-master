# 资产库与镜头管理交互核对

核对日期：2026-10-08。范围为当前代码和定向验证，不代表完整业务 E2E 验收。

| 差距 | 当前实现 | 操作入口 |
| --- | --- | --- |
| 分项级批量分配、排期 | 明确勾选分项，支持统一填写与逐项填写；未改动排期跳过；部分失败停止并保留逐项结果 | 资产列表勾选父资产后“选择分项批量操作”，资产详情分项批量管理 |
| 开工后调整制作要求、参考附件 | 受控调整任务要求、优先级、分项说明/备注；参考说明与附件采用追加并保留历史引用；整批锁校验、事务和审计 | 制作中或待修改分项“调整制作要求与资料” |
| 分项版本批量反馈、复核 | 以明确选中的分项最新版本为目标，复用审核上下文、问题复核、草稿和批量发送；返修期可批量追加问题 | 分项批量工作区“批量反馈与复核”“批量追加问题” |
| 人员泳道、甘特快捷操作 | 排期详情加载真实分项及可操作项，提供排期、开工、改派、制作调整、反馈、追加问题和详情入口 | 人员泳道或甘特点击任务条后的排期详情 |

批量管理不对整资产开工，不改变未选分项。开工保持每个分项单独确认；已开工分项不能普通改派。分配按制作人分组提交，排期逐项提交，失败不撤销先前已成功项；制作要求与资料调整、版本批量反馈继续遵循各自整批事务规则。参考附件当前支持追加，保留已有资料及历史，不提供删除已引用附件的入口。
