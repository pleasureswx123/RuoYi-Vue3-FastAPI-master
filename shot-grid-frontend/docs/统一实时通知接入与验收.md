# 统一实时通知接入与验收

## 当前行为

制作人的候选成功入库后，保持打开的审核详情收到通知，自动获取新增候选并显示数量提示。原候选预览和未提交意见保留。后补提示词同样触发更新。审核页显示实时连接状态；连接暂不可用时自动重连，前台每 30 秒校验一次。

目前只接入审核详情和版本变化事件，不包含审核列表、工作台或其他业务的全站通知。无需新增数据库迁移；生产需要发布后端、Shot Grid 前端及随附 Nginx 配置。

## 扩展方式

后端在 `module_realtime/service` 增加主题授权并复用发布格式，事件只能在事务提交成功后发送。前端页面通过 `useRealtimeStore.subscribe(topic, resourceId, listener)` 获取取消订阅函数，禁止各页面再创建独立 WebSocket。业务内容始终从现有鉴权 HTTP 接口读取，通知载荷禁止携带敏感内容。仅需版本状态的页面可复用 `useVersionRealtime`。

详细协议、安全限制和恢复边界见《领域模型与API契约》的统一 WebSocket 实时失效通知章节。
