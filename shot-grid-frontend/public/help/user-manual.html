Shot Grid 使用操作手册

本手册介绍项目准备、任务安排、作品提交、审核返修和成果查看的日常操作，适用于制作人员与项目管理与审核人员。

第一次使用：先选自己的角色

第一次登录，不必从头读完整本手册。先按下面的身份完成一次操作；需要时再通过目录查找详细说明。不同项目中的身份可能不同，请先核对当前项目和自己的角色。

我是制作人员：找到任务 → 提交作品 → 跟进结果

  1. 找到自己的任务。点击左侧“工作台” → “我的任务”。制作中的任务点击“继续制作”，待修改的任务点击“查看修改意见”，进入任务详情。
  2. 先看要求。核对项目、完整镜头编号或资产分项、主制作人，阅读“制作要求”、项目资料和参考附件。作品在自己的制作软件中完成。
  3. 确认可以提交。任务为“制作中”或“待修改”，且当前主制作人是自己。待排期、待开工时联系管理人安排；制作人员不能自行确认开工。
  4. 交第一版。在详情中的“提交首版成果”区域拖拽或选择文件，填写“首版交付说明”，点击“提交首版并进入审核”。具体步骤见第七章。
  5. 确认提交成功。等到正式版本号（如 V001）出现、任务变为“待审核”。上传进度到 100% 还不代表送审完成。
  6. 跟进结果。在“工作台” → “提交记录”查看版本；退回后按第九章修改并提交下一轮。任务“已完成”表示审核通过，文件交付状态另行查看。

今天没有任务？先清除筛选条件，确认账号正确，再请管理人核对是否已分配给你。不要为了提交作品自行新建项目或镜头。

我是项目管理与审核人员：准备任务 → 确认开工 → 审核作品

  1. 准备项目。已有项目直接使用；新项目在“项目” → “创建项目”中建立，添加制作成员，等待存储就绪。详见第三章。
  2. 准备制作对象。在“镜头管理”建立或导入镜头，在“资产库管理”建立资产及制作分项。先写清制作要求，再分配制作人。
  3. 安排工作。镜头点击“分配制作人”，资产按制作分项分配；设置计划起止时间。保存后核对负责人和时间，不能只看弹窗已关闭。
  4. 确认开工。资料与所需资产齐备后，在镜头行点击“确认开工”；资产选择具体分项确认。存储目录就绪后进入“制作中”。详见第六章。
  5. 等制作人提交，再审核。进入“工作台” → “待审核”，点击“进入审核”。审核单由系统随版本提交自动生成，无需手工创建。
  6. 作出结果。需要返修时发送问题，符合要求时确认通过；发送后核对状态，退回应为“待修改”，通过应为“已完成”。详见第八章。

只负责审核已有作品？直接从第五步开始。不要重复创建已有项目、镜头或任务。

1. 系统与角色

Shot Grid 用于管理影视制作中的项目、镜头、资产、任务、作品版本和审核反馈。视频、图片在专业制作软件中完成，通过 Shot Grid 提交、审核并保留制作记录。

项目只有两类人员角色：

  • 制作人员：查看本人任务和制作要求，制作作品，提交版本，按审核意见修改并说明处理结果。
  • 项目管理与审核人员：建立项目、维护成员和资料、分配任务、安排时间、确认开工，同时负责作品审核、反馈、返修复核和确认通过。界面中的“项目管理人”就是这一角色；手册中的“管理人”“审核人”均指此角色在不同操作环节的职责。

日常流程为：建立项目 → 准备镜头与资产 → 分配任务与排期 → 确认开工 → 制作与提交 → 审核 → 返修或通过 → 查看交付成果。

先用一个例子理解这些名称：某部短片是一个“项目”；其中的一段画面是一个“镜头”；角色、场景、道具是“资产”；角色正面图、侧面图分别是资产的“制作分项”。分配给某个人的工作叫“任务”；他每轮提交的作品叫“版本”。

例如，首次提交两个方案，仍是同一轮 V001，两个文件是本轮的“候选作品”；返修后提交下一轮 V002。审核单用于记录某一版本的审核过程。“NAS”是公司的共享文件存储，正式作品由系统保存到那里，不需要新手自己拼接保存路径。

2. 登录与页面导航

  1. 打开公司提供的系统地址，使用分配的账号登录。
  2. 在右上角确认当前账号，进入工作台查看任务与待办。
  3. 进入业务页面后，先选择“当前项目”，再查询或操作。
  4. 使用页面顶部的搜索查找业务对象；使用“使用手册”在新标签页查看本手册。
  5. 使用结束后，点击右上角“退出”。

主要菜单用途：

  • 工作台：制作人员查看本人任务；管理人查看制作进度与待审核事项。
  • 项目：建立项目，查看概况、资料、成员和存储状态。
  • 镜头管理：建立镜头清单，查询镜头，安排任务并查看制作履历。
  • 资产库管理：管理角色、场景、道具及其制作分项。
  • 版本审核：查看提交作品、记录问题、复核修改并作出审核结论。
  • 文件与 NAS：查找正式版本文件、下载作品并查看存储位置。

可见菜单和操作按钮取决于账号权限、项目成员身份及对象状态。看不到应有的项目或操作时，请管理人核对账号与项目成员设置。

3. 建立项目与维护资料

本节由项目管理与审核人员操作。

创建项目

  1. 在“项目”页面点击“创建项目”。
  2. 填写项目名称、代号、画幅等信息，选择可用的 NAS 根目录。
  3. 核对系统显示的项目保存路径，添加成员并选择项目角色，保留至少一名项目管理人。
  4. 按需填写项目描述、项目资料说明，上传剧本或参考附件。
  5. 确认创建，在项目详情查看初始化进度，等待存储就绪。

项目名称参与生成存储路径，创建前应核对正式名称。成员设为制作人员后，才能作为该项目的制作负责人接受任务。

维护成员和项目资料

在项目详情查看成员，按页面提供的入口添加成员、调整角色或移除成员。权限调整后，相关人员刷新页面或重新登录，以更新可见菜单与操作。

在“编辑项目”中维护项目共享资料。项目资料适用于整个项目；任务参考内容用于补充单个任务的要求。项目资料会在项目详情和所属任务详情中展示。

资料说明最多 10000 字；附件最多 5 个，每个不超过 20 MiB，支持图片、PDF、Office、TXT、MP4/MOV。图片可放大，视频可播放，文档可下载；浏览器无法播放的视频可下载后查看。

4. 建立与查询镜头

集、场次与镜头编号

镜头按“集 → 场次 → 镜头”组织。例如 EP001 / 000 / 0010 表示第一集、序场、镜头 0010。

  • EP001、EP002 等表示正片集；EP000 表示可选的预告片集。
  • 场次 000 表示所属集的“序”场。
  • 镜头号为正整数，在同一场次内不能重复，可以跳号。

手工创建

在“镜头管理”中依次使用“新建集”“新建场次”“新建镜头”。已有集和场次直接选择，无需重复创建。新建集填写 0 可建立预告片集；新建镜头填写镜头号和制作信息。

Excel 导入

  1. 确认当前项目，点击“导入 Excel”，下载官方模板。
  2. 保留模板表头和列结构，每个可见工作表代表一集，使用 EP001、EP002 等集号命名。预告片可使用 EP000 工作表。
  3. 填写场次和镜头号，按需补充其他制作信息；制作人员在导入完成后分配。
  4. 选择填写好的 .xlsx 文件，点击“预览导入内容”。
  5. 核对预览结果，修正错误行并重新预览，勾选本次需要导入的行。
  6. 确认导入并查看结果。导入后在镜头列表核对数量和编号；制作内容为空的镜头显示“待完善”，补齐后再分配制作人。导入不会自动给制作人安排任务。

查询与查看详情

通过关键字、集、场次、镜头号范围、状态或制作人筛选，点击“查询”；点击“重置”清除筛选条件。可切换“表格”“故事板”“人员泳道”“任务甘特”；表格或故事板用于查看镜头，泳道或甘特用于查看任务安排。点击行左侧展开箭头或“展开 / 收起详情”了解制作要求，使用“查看任务”或“制作履历”查看任务、版本和审核记录。

5. 建立资产与制作分项

本节由项目管理与审核人员操作。

  1. 在“资产库管理”中确认当前项目，按需新建角色、场景或道具，也可使用页面提供的 Excel 模板导入。
  2. 填写资产名称与说明，为资产建立制作分项，例如角色的正面图、侧面图、背面图。
  3. 展开资产行查看各分项，核对分项名称、制作要求、负责人和状态。
  4. 对需要制作的分项分配任务、安排时间并确认开工。

资产的分配、开工、提交与审核以制作分项为单位。一个分项开始或完成，不代表整个资产的其他分项同时开始或完成。查看资产详情可分别浏览各分项作品与历史记录。

在资产表格中展开资产，在具体制作分项行点击“设置排期”；已有完整时间时点击“调整排期”。资产详情中的分项也提供相同入口。排期权限独立于开工权限，保存时间不会自动开工；准备齐备后另点“确认开工”。点击“查看任务”可查看要求、提交作品、跟进审核和返修。

6. 分配任务、排期与开工

本节由项目管理与审核人员操作。

分配与排期

  1. 在“镜头管理”中点击目标镜头的“分配制作人”；在“资产库管理”中展开资产，进入对应制作分项的分配入口。选择该项目的制作人员，核对后确认保存。
  2. 查看制作要求，安排预期开始与结束时间。
  3. 使用项目排期、人员泳道或任务甘特查看任务安排；进入编辑模式后调整时间并保存；原因选填，可写明本次变更缘由。
  4. 出现同一制作人员的时间重叠提示时，核对工作安排后再决定是否确认。

预期时间用于计划与提醒，到达开始时间不会自动开工，到达结束时间也不会自动完成任务。

确认开工

  1. 确认所需角色、场景、道具及制作资料已齐备。
  2. 在镜头行点击“确认开工”；资产从开工入口选择具体制作分项（部分详情入口显示“开始任务”）。核对制作人员、制作要求、优先级和时间。
  3. 已有排期时核对当前安排；尚无排期时填写完整时间范围。
  4. 确认开工条件后点击“确认开工”。

目录尚未就绪时，任务显示“目录准备中”；进入“制作中”后，当前负责人可以提交作品。制作人员等待管理人确认开工。

调整制作任务

制作中的镜头可通过制作任务编辑入口修改允许调整的内容；批量调整前先选中目标镜头，再点击“批量编辑制作任务”。

按“选择字段 → 填写新值 → 核对保存”操作，按需填写调整原因，逐项比较原值和新值。未勾选的字段保留原内容，勾选后留空的普通文字字段会清空原内容；参考内容按追加方式保存。统一填写时应核对每个镜头是否适用。

7. 制作人员：查看任务与提交作品

入口：“工作台” → “我的任务” → 目标任务的“继续制作”。提交必须由当前受派的制作人员本人操作，管理人不能代提交。

  1. 在任务详情核对项目、镜头或资产分项、主制作人，阅读制作要求、项目资料、参考内容和计划时间。待开工时等待管理人确认，目录准备中时等待就绪。
  2. 在自己的专业软件中完成作品并导出文件：镜头任务使用 MP4/MOV，资产图片任务使用 JPG/PNG。
  3. 找到“提交首版成果”，在“选择首版候选成果”区域拖拽或选择文件。一轮可提交 1～10 个候选文件，单个不超过 100 MiB，整批不超过 500 MiB；以页面最新提示为准。
  4. 查看本地预览和文件列表，确认文件属于当前任务，移除选错的文件。多个候选是同一轮的不同方案，不是多轮提交。
  5. 填写“首版交付说明”，说明完成内容和希望审核人重点检查的地方；AI 生成提示词为选填。
  6. 点击“提交首版并进入审核”，等待文件上传、保存和版本生成。处理过程中不要重复点击提交。
  7. 确认出现正式版本号 V001，任务变为“待审核”。系统会自动生成本轮审核单，管理人可在“待审核”中处理。

怎样确认成功：上传进度到 100% 只表示上传阶段结束；正式版本生成并进入待审核，才表示本轮送审完成。到“工作台” → “提交记录”展开任务，可查看各轮版本。

失败或网络中断：先在当前任务查看提交进度，使用“刷新状态”核对结果。明确失败且页面允许重试时，点击本次提交对应的重试按钮；不确定是否成功时，不要重新发起一轮提交。

V001、V002 表示提交轮次；历史版本保留。修改后的作品通过下一轮提交，不覆盖旧作品。审核中若页面提供“追加候选并送审”，表示补充当前轮候选；正常返修按第九章提交新一轮。

8. 项目管理与审核人员：审核作品

审核单怎么来的：制作人员正式提交版本后，系统自动生成该版本的审核单。新手无需手工创建审核单；没有待审核内容时，先确认制作人是否已提交成功。

推荐入口：“工作台” → “待审核” → 目标作品的“进入审核”。也可打开“版本审核”，选择当前项目，展开任务行查看具体版本审核记录，再打开需要处理的一轮。请勿把历史版本的结果当成当前任务状态。

  1. 确认项目、任务与当前版本，阅读制作要求和本轮说明。
  2. 播放视频或查看图片；有多个候选时逐一查看并选择本轮最佳候选。
  3. 对具体画面记录问题，按需定位时间点、添加画面标注或参考附件；通用意见填写整体反馈。
  4. 有历史问题时，对照制作人员的处理说明逐条复核。
  5. 需要修改时，说明问题和修改目标，执行“退回并发送问题”。
  6. 符合要求时，确认历史问题均已解决且没有待处理问题，再点击“全部符合，确认通过”，核对确认窗口后点击“确认通过并交付”。

“保存问题草稿”仅保存审核方的待整理意见，制作人员暂时不可见。需要制作人员返修时，应完成退回发送操作。“稍后决定”用于保留待审核状态，后续继续处理。

批量反馈按“复核已有问题 → 补充反馈 → 确认发送”操作。共同意见作用于全部选中对象；已符合要求的作品应移出退回范围并单独通过。保存新增反馈草稿仅保存新增意见，不会发送返修，也不会保存历史问题的复核结论。

怎样确认结果：退回发送后，制作人任务变为“待修改”，才能按本轮问题返修；通过后任务为“已完成”。草稿保存成功不等于已经发送；“稍后决定”也不会让制作人进入返修。

一次给多个镜头反馈

  1. 在“镜头管理”表格中勾选需要一起反馈的镜头，点击“批量反馈与复核”。该操作处理已提交的作品，不是手工创建审核单。
  2. 在“复核已有问题”逐条检查。选择“已解决”或“仍需修改”；仍需修改时说明原因。使用“定位下一条待复核问题”找到遗漏项，完成全部必需复核后再下一步。
  3. 在“补充反馈”填写共同意见，并按需补充各镜头的单独意见。共同意见会作用于全部选中镜头，不适用的作品应移出本次范围。
  4. 在“确认发送”核对镜头、版本、问题和返修范围，再发送。已符合要求的作品单独审核通过。

9. 制作人员：返修与再次提交

  1. 在“工作台” → “我的任务”找到“待修改”任务，点击“查看修改意见”，查看整体反馈、具体问题、画面标注和参考资料。
  2. 在专业软件中修改作品。
  3. 找到“提交修改成果”，对每条待处理问题选择“已处理”或“未处理”；未处理时填写说明，再核对修改后的文件。
  4. 填写“本轮修改说明”，选择修订作品，点击“提交修改成果并重新送审”。
  5. 确认下一轮正式版本号（如 V002）出现、任务回到“待审核”，再等待管理人复核。

制作人员的“已处理”表示本轮处理说明。管理人会在新版本中确认问题是否解决；未解决的问题继续进入后续修改流程。

10. 状态与进度

  • 待完善（镜头）：制作内容尚未补齐，由管理人点击“完善信息”补齐后再分配。
  • 待排期：已有制作人但计划起止时间不完整，由管理人设置排期；制作人员不能提交。
  • 待分配：尚无制作负责人，由管理人分配。
  • 待开工：已分配任务，等待管理人确认开工。
  • 目录准备中：正在准备作品存储目录，等待就绪。
  • 制作中：制作人员可以制作并提交作品。
  • 待审核：作品已提交，等待管理人审核。
  • 待修改：已收到返修意见，制作人员修改后提交下一版本。
  • 已完成：作品审核通过，可查看最终版本及交付状态。

时间提醒独立于制作状态，显示正常、临近结束、已延期或未设置时间。项目整体完成度按已完成镜头与资产制作分项的数量统计；资产状态汇总其分项，具体进展可展开查看。

11. 查看版本、下载与交付

  1. 在任务详情或制作履历查看历次版本、候选作品和审核记录。
  2. 通过版本详情或“文件与 NAS”查找正式文件，确认所属项目、任务和版本。
  3. 点击下载，将副本保存到浏览器设置的下载位置。
  4. 审核通过后查看最终交付状态，确认最终版本已发布到 NAS。

正式作品由系统保存到项目 NAS 存储。页面显示的存储路径用于定位共享目录，下载副本保存在本机。审核通过与最终文件交付是两个状态，应分别核对。项目归档后保留历史资料供查询。

12. 常见问题与求助

看不到项目、任务或按钮怎么办？

先核对右上角账号和当前项目，清除关键字、状态、制作人等筛选条件。仍看不到时，请管理人核对项目成员身份、负责人和权限。调整权限后刷新或重新登录。按钮是否可用也取决于对象状态，并非所有人随时都能操作。

为什么不能上传或提交作品？

先确认自己是当前主制作人，再看任务状态：待排期请管理人设置时间，待开工请管理人确认开工，目录准备中需等待存储就绪。待审核先等结论，已完成任务查看成果。项目归档后停止业务写入。检查文件格式、数量和大小，以及必填说明；资产分项内容缺失时请管理人补齐。

一直显示“目录准备中”怎么办？

稍后刷新核对。持续未完成或出现失败提示时，联系管理人核查项目存储与目录处理；提供任务和提示内容。不要通过重新分配、重复创建对象来尝试绕过。

为什么审核人看不到刚提交的作品？

制作人先确认正式版本已生成、任务已待审核。管理人再核对项目、筛选条件和管理范围，刷新“待审核”。若仍缺失，提供版本号与提交时间供管理员核查。

保存了问题草稿，制作人为什么没有收到？

草稿只供审核方整理意见。确认需要返修后，点击“退回并发送问题”并完成确认；制作人收到的是发送后的意见。只点“保存问题草稿”或“稍后决定”不会发起返修。

制作人已标记“已处理”，为什么问题还没关闭？

“已处理”是制作人对本轮修改的说明，管理人还需在新作品上复核。审核人确认已解决后，该问题才关闭；仍需修改的问题继续跟随后续版本。

审核通过了，为什么最终文件还没交付？

审核通过与最终文件发布到 NAS 是两个步骤。在任务或版本详情核对交付状态；处理中等待，失败时联系管理人。不要把“已完成”当作最终文件已发布成功的证明。

提交中断、数据冲突或批量操作部分失败怎么办？

先刷新并查询实际结果，核对哪些项目已经成功，再处理剩余项。不要对整个批次盲目重复提交。数据变化或冲突时，以最新负责人、状态和内容为准重新核对。

联系管理人时提供什么？

提供项目名称、完整镜头编号或资产分项名称、版本号、操作时间、点击步骤及页面错误提示；必要时附截图。不要发送密码或登录凭证。浏览器打印可将本手册保存为 PDF。
