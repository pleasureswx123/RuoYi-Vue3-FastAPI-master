## 本轮发现和修复

1. **发布期间默认仍可写入**：发布脚本现在必须在备份前停止本项目后端，保持停写至迁移、预检结束并切换新版本。显式关闭停写会提前拒绝；远程发布入口默认停写并拒绝 false。失败不自动恢复旧写服务，需维护窗口。
2. **发布与回滚可能并发**：回滚复用发布的 deploy.lock，并在持锁后读取版本指针。并发请求在任何 Docker 切换前被拒绝。
3. **PostgreSQL 健康状态可能提前成功**：生产及开发 Compose 的健康检查改为 TCP 127.0.0.1，避免把初始化 SQL 尚未完成时的临时 Unix socket 服务当作正式就绪。延迟初始化的独立容器已实际复现旧探针提前成功，确认新探针等待正式服务后才成功；临时容器及其卷已精确清理。
4. **Windows CLI 补全安装偶发失败**：Click 生成 Bash 脚本时执行宿主 Bash/WSL 版本探测，可能把非 UTF-8 输出当作 UTF-8 解码，引发异常。现只生成跨机器可用的脚本，保留原有 Bash 兼容指令转换，不执行宿主版本探测。新增模拟非 UTF-8 探测输出的回归；相关 CLI 127 项通过。
5. **依赖安全告警**：初次生产依赖审计，管理端 18 项（11 高危、1 严重），Shot Grid 6 项（4 高危）。升级两端 Axios 至 1.21.1、Vite 至 6.4.6，管理端 Vue 至 3.5.45、DOMPurify 统一为 3.4.17；Mermaid 保持 11.16.1，将其间接 KaTeX 固定到修复版 0.18.2，避免为安全修复强行跨 Mermaid 主版本；移除无源码引用的 @antv/g2plot 及其旧 Rollup 链。Shot Grid 测试工具 Vitest 升级至 4.1.11。同步 npm 锁文件；CI 新增生产依赖高危/严重告警门禁，不使用 audit fix --force 的自动降级建议。

6. **Python 依赖漏洞**：原运行环境审计检出 6 个包共 67 项已知告警，涉及 Pillow、PyJWT、certifi、dnspython、urllib3 和 setuptools。分别升级至 13.0.0、2.15.0、2026.10.18、2.9.2、2.8.0 和 84.1.0；生产镜像同时锁定 pip 26.2.1。生产 Dockerfile 改用完整 PostgreSQL 锁文件，实际镜像 `pip check` 通过；锁文件和独立 Windows 验收环境最终 pip-audit 均无已知漏洞。原虚拟环境不覆盖，升级仅在新的验收环境及镜像中进行。Pillow 13 最低 Python 3.11，仓库最低版本、CLI 元数据和 CI 同步为 3.11；生产仍为 3.11.15。
7. **镜像夹带验收输出**：原候选镜像包含 output 中的 333 个文件、约 52 MB；不据此推断含敏感数据。后端 Docker 忽略 output、Playwright 输出、覆盖率及日志。新镜像实际断言 `/app/output` 和 `/app/.env.*` 不存在。
8. **测试工具迁移与资源预算**：Vitest 4 不再通过 restoreMocks 重置 vi.fn，一次性响应残留使资产导入用例串扰。显式重置模拟实现与队列，保持业务断言不变。完整组件回归初轮发生内存不足；最终采用单 Worker 分批执行并按 Vitest 收集清单逐项核对。一次批量分配用例与镜像构建并发时触发 5 秒超时，构建结束后原批次 25 项复测全部通过，没有延长超时或放宽断言。

9. **前端运行时 Nginx 过旧**：两个正式 Dockerfile 从 1.27-alpine 升级到 1.30.6-alpine，依据 [Nginx 官方安全公告](https://nginx.org/en/security_advisories.html) 及 [稳定版下载记录](https://nginx.org/en/download.html)。这项修复独立于 npm 依赖升级，需重新构建镜像并复核代理和二进制下载；不代表已完成所有系统包 CVE 扫描。
